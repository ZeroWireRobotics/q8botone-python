The Q8botOne desktop app, ready to run - no Python needed - for Windows, macOS (Apple Silicon) and Linux.

## What's new

**Drive a simulated Q8botOne.** The app now carries Q8botOne's physics model (in [MuJoCo](https://mujoco.org)). Pick **Simulated robot** in the Connection list and click **Connect**: the app drives the simulation exactly as it drives the robot - the robot's own gaits, its servos at their real speed - so you can try everything before your robot arrives. The model is in [q8botone-sim](https://github.com/ZeroWireRobotics/q8botone-sim), and runs in your browser too on [zerowirerobotics.com](https://zerowirerobotics.com).

**A live 3D view.** With your robot connected, the 3D view shows its legs moving as the robot measures them. With an MPU6050 on the robot's Qwiic port, **Calibrate IMU** (once, about 15 s) finds how the sensor is mounted, and the model then tilts, turns and walks along with the robot.

**Keep Level** (new, early - tried in simulation so far): with an MPU6050, holds the body level while the robot stands, on a slope or a board tipped under it.

**Leg geometry from the CAD.** The app and the robot's gaits now use the legs' real lengths, so stances stand at the height they're meant to. This needs firmware **0.2.2** on the robot and the controller - included, see below.

Also since 0.1.0: the robot's Qwiic sensors (INA237, MPU6050) with live plots, `move(forward, turn)` and other library additions, a walking robot stopped reliably when the app closes, and the controller found automatically.

## Downloads

| | |
|---|---|
| Windows | `Q8botOne-0.2.0-windows-x64.exe` - Windows may say it doesn't recognize the app: **More info**, then **Run anyway** |
| macOS (Apple Silicon) | `Q8botOne-0.2.0-macos-arm64.zip` - unzip, move **Q8botOne.app** to Applications. It isn't signed by Apple yet: the first time, right-click it and choose **Open** (if macOS says it's damaged, run `xattr -dr com.apple.quarantine /Applications/Q8botOne.app` in Terminal) |
| Linux (x64) | `Q8botOne-0.2.0-linux-x64.tar.gz` - unpack and run `./Q8botOne`. For USB access to the controller, add yourself to the `dialout` group; on Ubuntu, Qt may need `sudo apt install libxcb-cursor0` |
| Firmware Flasher (Windows) | `Q8botOne-Firmware-Flasher-0.2.2-windows-x64.zip` - puts firmware 0.2.2 on the robot and the controller over USB; instructions inside |

Firmware 0.2.2 (protocol 3) is [tagged in q8botone-firmware](https://github.com/ZeroWireRobotics/q8botone-firmware/releases/tag/v0.2.2).
